# ЮрКонсультант ИИ

## Пользовательская документация

**ЮрКонсультант ИИ** — это веб-система для получения первичной юридической информации с помощью чат-бота. Пользователь может задать юридический вопрос в свободной форме, получить справочный ответ, посмотреть историю консультаций и оставить оценку качества ответа.

Система предназначена для пользователей, которым нужно быстро разобраться в юридической ситуации, получить общее объяснение, понять возможный порядок действий или расшифровать юридический термин простым языком.

> Важно: система не заменяет профессионального юриста, адвоката или официальную юридическую консультацию. Ответы чат-бота носят справочный характер. В сложных, спорных, срочных или финансово значимых ситуациях рекомендуется обращаться к специалисту.

---

## 1. Назначение системы

Система «ЮрКонсультант ИИ» предназначена для предоставления пользователям первичной юридической информации в формате чат-бота.

Основные возможности системы:

- приём юридических вопросов пользователя;
- формирование справочного ответа;
- использование правового контекста при подготовке ответа;
- объяснение юридических терминов простым языком;
- предоставление пошаговых инструкций по типовым ситуациям;
- сохранение истории консультаций;
- получение обратной связи от пользователя;
- предоставление административных инструментов для управления материалами системы.

Система может быть полезна гражданам, студентам, представителям малого бизнеса и другим пользователям, которым требуется быстро получить общее понимание юридической ситуации.

## 2. Условия применения

Для работы с системой пользователю необходимы:

- устройство с доступом в интернет;
- современный веб-браузер;
- доступ к веб-приложению «ЮрКонсультант ИИ»;
- учётная запись пользователя.

Пользователь взаимодействует с системой через веб-интерфейс.

В приложении предусмотрены две основные страницы:

- `/` — пользовательская страница чат-бота;
- `/admin` — административная панель.

---

## 3. Роли пользователей

В системе предусмотрены две основные роли.

### Пользователь

Пользователь может:

- задавать юридические вопросы;
- получать ответы чат-бота;
- просматривать историю консультаций;
- открывать прошлые диалоги;
- оставлять оценку ответа;
- отправлять комментарий к ответу.

### Администратор

Администратор может:

- управлять правовыми материалами;
- управлять типовыми ситуациями;
- управлять пользователями;
- изменять настройки поведения бота;
- просматривать статистику системы;
- анализировать качество ответов.

Доступ к административным функциям должен быть только у пользователей с ролью `admin`.

## 4. Начало работы

Для начала работы необходимо открыть веб-приложение «ЮрКонсультант ИИ» в браузере.

После открытия пользовательской страницы пользователь получает доступ к чату. Если пользователь ещё не вошёл в систему, необходимо пройти авторизацию.

### Вход в систему

Для входа указываются:

- email;
- пароль.

Если пользователь входит впервые, система автоматически создаёт новую учётную запись с ролью обычного пользователя.

Если пользователь уже существует, система проверяет введённый пароль.

После успешного входа пользователь может пользоваться чат-ботом, задавать вопросы и просматривать историю своих консультаций.

## 5. Как задать юридический вопрос

Чтобы получить более полезный ответ, вопрос нужно формулировать понятно и конкретно.

Рекомендуется указать:

- что произошло;
- кто участвует в ситуации;
- какие документы или обстоятельства есть;
- что пользователь хочет получить в результате;
- есть ли сроки, претензии, договоры, чеки, переписка или другие доказательства.

### Пример плохого вопроса

```text
Что делать с договором?

### Пример хорошего вопроса

```text
Я заключил договор оказания услуг, оплатил работу, но исполнитель не выполнил услугу в срок. Договор и чек есть. Что я могу сделать и как правильно составить претензию?
```

Чем точнее описана ситуация, тем проще системе подобрать подходящий правовой контекст и сформировать понятный ответ.

---

## 6. Как работает ответ чат-бота

После отправки вопроса система выполняет несколько действий:

1. Находит или создаёт диалог пользователя.
2. Сохраняет сообщение пользователя.
3. Получает актуальные настройки бота.
4. Ищет релевантный правовой контекст.
5. Формирует запрос к языковой модели.
6. Получает ответ.
7. Сохраняет ответ в истории консультации.
8. Показывает ответ пользователю.

Для подготовки ответа используется RAG-подход. Система может искать релевантные фрагменты нормативно-правовых материалов в векторном хранилище, а затем передавать найденный контекст языковой модели для формирования ответа.

Если подходящий правовой контекст найден, ответ формируется с учётом найденных материалов. Если контекст не найден, система может дать общий справочный ответ, но такой ответ требует более внимательной проверки пользователем.

## 7. Как читать ответ системы

Ответ чат-бота может включать несколько смысловых блоков.

### Краткое объяснение ситуации

Система простыми словами описывает, как можно понимать вопрос с юридической точки зрения.

### Нормативная основа

Если система нашла подходящие правовые материалы, она использует их как контекст для ответа.

### Возможные действия

Пользователь может получить примерный порядок дальнейших шагов:

- какие документы собрать;
- куда обратиться;
- как оформить претензию;
- что уточнить;
- какие сроки учитывать.

### Предупреждение об ограничениях

В сложных ситуациях ответ нужно дополнительно проверить у юриста.

## 8. Типовые ситуации

Раздел «Типовые ситуации» предназначен для распространённых юридических случаев, где пользователю можно предложить готовый пошаговый алгоритм действий.

Примеры типовых ситуаций:

- залив квартиры соседями;
- возврат товара;
- спор по договору;
- некачественно оказанная услуга;
- претензия к организации;
- вопросы по задолженности;
- конфликт с работодателем.

Типовая ситуация обычно содержит:

- название;
- категорию;
- пошаговую инструкцию.

## 9. Объяснение юридических терминов

Систему можно использовать не только для разбора ситуаций, но и для объяснения юридических понятий.

Примеры вопросов:

```text
Что такое исковое заявление?
```

```text
Что значит досудебная претензия?
```

```text
Что такое неустойка?
```

```text
Чем отличается договор от соглашения?
```

```text
Что значит срок исковой давности?
```

При таких запросах лучше прямо указывать, что требуется объяснение простыми словами.

Пример:

```text
Объясни простыми словами, что такое досудебная претензия и когда она нужна.
```

## 10. История консультаций

Система сохраняет диалоги пользователя. Это позволяет вернуться к прошлым вопросам и повторно посмотреть ответ.

В истории отображаются консультации пользователя, отсортированные от новых к старым. Также можно открыть конкретный диалог и посмотреть все сообщения внутри него в хронологическом порядке.

История полезна, если пользователь хочет:

- вернуться к предыдущей консультации;
- продолжить разбор ситуации;
- сравнить несколько ответов;
- сохранить порядок действий;
- использовать ответ при подготовке документов.

---

## 11. Оценка ответа и обратная связь

После получения ответа пользователь может оставить обратную связь.

Оценка может быть:

- положительной;
- отрицательной;
- с текстовым комментарием.

Обратная связь нужна для контроля качества ответов. Она помогает понять, какие ответы были полезными, а какие требуют улучшения.

### Когда стоит поставить положительную оценку

Положительную оценку стоит поставить, если ответ:

- понятный;
- соответствует вопросу;
- помогает разобраться в ситуации;
- содержит полезный порядок действий.

### Когда стоит поставить отрицательную оценку

Отрицательную оценку стоит поставить, если ответ:

- не относится к вопросу;
- слишком общий;
- непонятный;
- содержит ошибку;
- не помогает решить ситуацию.

В комментарии желательно кратко указать, что именно было не так.

## 12. Ограничения системы

Система имеет ряд ограничений.

### Ответ не является юридическим заключением

Чат-бот предоставляет справочную информацию, а не официальную позицию юриста.

### Ответ зависит от полноты вопроса

Если пользователь описал ситуацию слишком кратко, система может дать общий ответ.

### Система может не учитывать все детали дела

В реальных юридических ситуациях важны документы, сроки, доказательства, регион, судебная практика и другие обстоятельства.

### Сложные случаи требуют специалиста

Если вопрос связан с судом, крупными суммами, уголовной ответственностью, недвижимостью, наследством, увольнением или срочными сроками, рекомендуется обратиться к юристу.

### Ответ нужно проверять

Перед подачей документов, претензий или обращением в суд необходимо дополнительно проверить информацию.

## 13. Раздел администратора

Административная панель предназначена для пользователей с ролью `admin`.

Обычный пользователь не должен иметь доступ к административным функциям. Все административные маршруты защищены проверкой: пользователь должен быть аутентифицирован и иметь роль администратора.

Административная панель открывается отдельно от пользовательской страницы:

```text
/admin
```

## 14. Управление правовыми материалами

Администратор может управлять правовыми материалами, которые используются системой при подготовке ответов.

Доступные действия:

- просмотр списка правовых материалов;
- просмотр одного материала;
- добавление нового материала;
- изменение существующего материала;
- удаление материала.

При создании правового материала он сохраняется в основной базе данных и индексируется в ChromaDB, чтобы его можно было использовать для семантического поиска.

При изменении текста или заголовка материал переиндексируется.

При удалении материал удаляется из основной базы данных и из ChromaDB.

---

## 15. Управление типовыми ситуациями

Администратор может создавать и редактировать типовые ситуации.

Типовая ситуация — это заранее подготовленный сценарий с пошаговой инструкцией. Такие сценарии нужны для часто повторяющихся юридических вопросов.

Доступные действия:

- просмотр списка типовых ситуаций;
- просмотр конкретной ситуации;
- создание новой ситуации;
- редактирование ситуации;
- удаление ситуации.

---

## 16. Управление пользователями

Администратор может просматривать пользователей, изменять их роли и удалять учётные записи.

В системе используются роли:

- `user` — обычный пользователь;
- `admin` — администратор.

При изменении роли нужно соблюдать осторожность. Администратор не должен случайно лишить себя доступа к административной панели.

---

## 17. Настройка поведения бота

Администратор может управлять конфигурацией бота.

К настройкам относятся:

- системный промпт;
- температура генерации;
- максимальное количество токенов;
- список ограниченных тем.

Эти настройки позволяют менять поведение бота без изменения программного кода.

## 18. Статистика и качество ответов

Администратор может просматривать агрегированную статистику работы системы.

В статистику входят:

- общее количество пользователей;
- количество администраторов;
- количество диалогов;
- количество сообщений;
- количество сообщений пользователей;
- количество сообщений бота;
- количество отзывов;
- количество положительных оценок;
- количество отрицательных оценок;
- количество правовых материалов;
- количество типовых ситуаций.

Эти показатели помогают оценивать активность пользователей и качество работы системы.

## 19. Частые вопросы

### Зачем нужна авторизация?

Авторизация нужна, чтобы система могла сохранять историю консультаций конкретного пользователя и показывать ему его прошлые диалоги.

### Что делать, если система дала слишком общий ответ?

Нужно уточнить вопрос: добавить факты, даты, документы, участников ситуации и желаемый результат.

### Почему в ответе может не быть ссылок на НПА?

Система может не найти подходящий правовой контекст в базе материалов. В таком случае она формирует общий справочный ответ.

### Можно ли использовать ответ как готовый юридический документ?

Нет. Ответ можно использовать как основу для понимания ситуации, но готовые документы лучше проверять у специалиста.

### Можно ли вернуться к прошлому вопросу?

Да. Для этого используется история консультаций.

### Что делать, если ответ неверный?

Нужно поставить отрицательную оценку и оставить комментарий. Это поможет улучшить качество работы системы.
