ЮрКонсультант ИИ — Документация разработчика
=============================================

Веб-приложение «Юридический консультант на основе ИИ» — модульный
монолит на FastAPI с RAG-поиском по нормативно-правовой базе и
интеграцией с LLM Gemini.

Архитектура
-----------

Приложение разнесено по слоям:

* ``app/api/`` — HTTP-роутеры FastAPI.
* ``app/services/`` — бизнес-логика (чат, обратная связь, админ-операции).
* ``app/core/`` — утилиты безопасности и FastAPI-зависимости.
* ``app/models.py`` — ORM-модели SQLAlchemy.
* ``app/schemas.py`` — Pydantic-схемы запросов/ответов.
* ``app/database.py`` — конфигурация подключения к БД.

Хранение данных:

* PostgreSQL / SQLite — основная реляционная БД (пользователи,
  диалоги, сообщения, фидбэк, НПА, сценарии, конфигурация бота).
* ChromaDB — векторное хранилище фрагментов НПА для семантического
  поиска RAG-сервисом.
